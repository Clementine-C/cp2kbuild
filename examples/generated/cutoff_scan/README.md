# CP2K convergence scan

Generated by cp2kbuild 0.1.0.
Varied: CUTOFF = [400, 600]
Property: energy

## How to run

```sh
sh cutoff_run.sh
sh cutoff_analyse.sh
```

所有输入文件都在这一个目录里，运行脚本按参数顺序列好了；也可以只跑其中几个：`sh cutoff_run.sh 1 5 9`。

并行：`NPROC_PER_CALC`（每个算例几个 MPI 进程）× `NPROC_TOTAL`（总共几个）。都是 1 就是串行。

## How to read the results

在集群上跑分析脚本（只需要 sh + awk，不需要 Python）：

```sh
sh cutoff_analyse.sh
```

它从每个 `.out` 里读 CUTOFF / REL_CUTOFF / 能量 / 每档网格点数，
写成 `cutoff_data.ssv` / `rel_cutoff_data.ssv`，并把表打到屏幕上；
末尾会打印每原子差值（相对最细的那次）。取哪一档由你判断。

## With cp2kbuild instead

`cp2kbuild converge <目录>` 也会读同一批输出（不需要集群上有 Python）。
